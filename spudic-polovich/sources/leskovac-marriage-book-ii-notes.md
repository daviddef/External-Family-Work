# Leskovac-Barilovićki marriage book II, images 468 onward — reading notes

Volume: FamilySearch "Croatia, Church Books, 1516-1994", Leskovac-Barilovićki births/marriages 1832-1857, deaths 1782-1857 (waypoint 9R2M-YW1), https://www.familysearch.org/ark:/61903/3:1:3QS7-L99C-59HB-R

Method: FamilySearch image viewer, 3x zoom, panned page by page (right page then left page, top to bottom). Image numbers are the viewer's "Image N of 644". Each image is a two-page spread. Quotes are as read; `(?)` marks uncertain handwriting. "conf. Barilovichensis" = a Military Frontier soldier of the Barilovich company; many entries 1837-39 are soldiers, not Leskovac peasants.

Images 464-467 (1832 to Nov 1835) were read by the parent session and are not repeated here.
